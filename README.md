# cardboard-robotic-arm
Arduino-based cardboard robotic arm using four SG90 servo motors.
Components

I used:

1 Arduino UNO
4 SG90 servo motors
Cardboard for making the robotic arm
Breadboard
Jumper wires MALE TO MALE,FEMALE TO MALE,FEMALE TO FEMALE-20 EACH
4×AA battery holder and 4 AA batteries
USB cable for Arduino connection to the computer
Glue for attaching the cardboard parts
ice-cream sticks

Arduino Connections:
Base servo → D2
Elbow servo → D3
Shoulder servo → D4
Gripper servo → D5
adruino gnd to breadboard gnd
adruino 5v to breadboard +
